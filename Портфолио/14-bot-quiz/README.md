# 🧠 Quiz Bot — викторина для Telegram-сообществ

Telegram-бот, который проводит викторины в группах: публикует вопросы через
нативный Telegram-опрос типа **quiz** (с правильным ответом и пояснением),
считает очки, ведёт таблицу лидеров сезона и подводит итоги. Вопросы хранятся
в банке по категориям, банк пополняется вручную админом или импортом из JSON.

> Учебно-портфолийный проект. Стек: **aiogram 3**, **SQLAlchemy 2** (async),
> **PostgreSQL** (в продакшене) или **SQLite** (локально), **APScheduler**.

## ✨ Что умеет

- **Нативные quiz-опросы Telegram** — правильный ответ и пояснение показывает
  сам мессенджер, ответы неанонимные (нужно, чтобы начислять очки).
- **Три режима игры:**
  - `daily` — одиночный «вопрос дня» (по команде или по расписанию);
  - `marathon` — серия вопросов подряд с паузами;
  - `blitz` — быстрая серия коротких опросов.
- **Подсчёт очков** с опциональным бонусом за скорость (чем быстрее ответ —
  тем больше бонус, линейно затухает до нуля).
- **Защита от повторного ответа** — один ответ на опрос от пользователя
  (гарантируется уникальным индексом `(poll_id, user_id)` в БД).
- **Сезоны и таблица лидеров** — очки копятся в рамках сезона, `/newseason`
  обнуляет зачёт, `/endseason` подводит итоги и называет победителей.
- **Банк вопросов по категориям** — пополнение мастером `/addquestion` и
  импорт сидов из JSON (идемпотентно, без дублей).
- **Расписание** — `/daily on` подписывает чат на автоматический вопрос дня,
  который публикуется каждый день в заданное время (APScheduler).
- **RU / EN** — язык переключается на уровне чата (`/lang ru|en`).
- Логирование, rate-limit на команды, обработка ошибок и флуд-контроля Telegram.

## 🚀 Быстрый старт (локально, SQLite)

Требуется Python 3.9+.

```bash
cd 14-bot-quiz
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env               # впишите BOT_TOKEN и ADMIN_IDS
python -m bot
```

При первом запуске бот создаёт таблицы и импортирует стартовые вопросы из
`data/seed_questions.json`. По умолчанию используется SQLite-файл `data/quiz.db`.

### Обязательные переменные окружения

| Переменная   | Назначение                                             |
|--------------|--------------------------------------------------------|
| `BOT_TOKEN`  | Токен бота от [@BotFather](https://t.me/BotFather)      |
| `ADMIN_IDS`  | ID админов через запятую (узнать: [@userinfobot](https://t.me/userinfobot)) |
| `TZ`         | Часовой пояс для расписания (например `Europe/Moscow`)  |
| `DB_*`       | Параметры PostgreSQL (при `DB_ENGINE=postgres`)         |

Полный список — в [`.env.example`](.env.example).

## 🤖 Как добавить бота в чат

1. Создайте бота у [@BotFather](https://t.me/BotFather), получите `BOT_TOKEN`.
2. В настройках бота у BotFather включите приём сообщений в группах
   (**Group Privacy → Turn off**), иначе бот не увидит команды в группе.
3. Добавьте бота в группу и назначьте **администратором** (право отправлять
   сообщения и создавать опросы).
4. Пропишите свой Telegram ID в `ADMIN_IDS`.
5. В группе выполните `/newseason Сезон 1`, затем `/quiz` — полетели.

## 🎮 Команды

**Участники**

| Команда        | Действие                          |
|----------------|-----------------------------------|
| `/leaderboard` | таблица лидеров сезона            |
| `/myscore`     | ваши очки                         |
| `/lang ru\|en` | язык бота в этом чате             |
| `/help`        | справка                           |

**Администраторы**

| Команда               | Действие                                    |
|-----------------------|---------------------------------------------|
| `/quiz [категория]`   | одиночный вопрос                            |
| `/marathon [кат.]`    | серия вопросов                              |
| `/blitz [кат.]`       | быстрый блиц                                |
| `/addquestion`        | добавить вопрос (пошаговый мастер)          |
| `/daily on\|off`      | авто-вопрос дня по расписанию               |
| `/newseason Название` | начать новый сезон (обнулить зачёт)         |
| `/endseason`          | закрыть сезон и объявить победителей        |
| `/results`            | текущие итоги сезона                        |
| `/categories`         | список категорий банка                      |

### Формат вопроса в `/addquestion`

Мастер спросит категорию, язык, текст и варианты. Варианты вводятся по одному
на строку, правильный помечается `*` в начале:

```
*Канберра
Сидней
Мельбурн
Перт
```

### Формат сид-файла (JSON)

```json
[
  {
    "category": "География",
    "lang": "ru",
    "text": "Столица Австралии?",
    "options": ["Сидней", "Мельбурн", "Канберра", "Перт"],
    "correct_index": 2,
    "explanation": "Столица Австралии — Канберра."
  }
]
```

Файл `data/seed_questions.json` подхватывается автоматически при старте.
Импорт идемпотентен: повторный запуск не создаёт дубликатов.

## 🐳 Деплой через Docker (PostgreSQL)

```bash
cp .env.example .env    # впишите BOT_TOKEN и ADMIN_IDS
docker compose up -d --build
```

`docker-compose.yml` поднимает PostgreSQL и бота; переменные `DB_ENGINE=postgres`
и `DB_HOST=db` уже проставлены для сервиса бота. Данные БД хранятся в томе
`pgdata`. Логи: `docker compose logs -f bot`.

## ⚙️ Как считаются очки

- Неверный ответ — `0`.
- Верный — `BASE_POINTS` (по умолчанию 10) плюс бонус за скорость.
- Бонус линейно убывает от `SPEED_BONUS_MAX` (мгновенный ответ) до `0`
  на границе окна `SPEED_WINDOW_SECONDS`. Отключается установкой
  `SPEED_BONUS_MAX=0`.

Повторный ответ на тот же опрос от того же пользователя не засчитывается —
это гарантирует уникальный индекс `(poll_id, user_id)` на уровне БД.
