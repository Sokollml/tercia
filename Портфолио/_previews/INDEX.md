# Превью проектов (для фриланс-бирж)

Скриншоты сняты headless-Chrome в retina ×2. По каждому проекту:
- `*-hero.png` — чистая обложка 2880×1800 (первый экран) → **для карточки проекта на бирже**
- `*-desktop.png` — вся страница целиком, десктоп → для детального превью
- `*-mobile.png` — вся страница, мобайл 375px → показать адаптив

```
_previews/
├── 04-landings/
│   ├── 00-index/            (общий индекс 4 лендингов)
│   ├── 01-saas-swiss/       SaaS-аналитика, Swiss-стиль (красный/чёрный/белый)
│   ├── 02-coffee-editorial/ Кофейня, Editorial (кремовый serif)
│   ├── 03-app-tactile/      Моб. приложение, Tactile (тёмный премиум + мокап)
│   └── 04-course-maximalist/ Онлайн-курс, Maximalist (яркая типографика)
├── 23-showcase/             витрина портфолио (в стиле tercia.dev)
├── 01-wp-restaurant/        сайт ресторана (home / menu / gallery)
├── 02-wp-fitness/           сайт фитнес-студии (home / schedule)
└── 03-wp-plugin/            демо блока отзывов (Gutenberg)
```

Для карточки на бирже бери `*-hero.png`. Для галереи внутри проекта — добавь `*-desktop.png` (весь дизайн) и `*-mobile.png` (адаптив).

### Mini-apps (сняты с мок-оболочкой Telegram + подставленными данными)
```
├── 17-miniapp-habits/       трекер привычек (app-mobile / app-hero)
├── 18-miniapp-loyalty/      карта лояльности кафе
└── 19-miniapp-freelance-orders/ поиск фриланс-заказов
```

Сняты на 390px в тёмной/светлой теме Telegram, с реалистичными данными (привычки/серии, штампы карты, лента заказов). Для биржи бери `app-mobile.png`.
