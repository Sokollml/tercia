# Плагины для сайта Verano

Рекомендованный набор плагинов для боевого запуска. Тема и тип записи «Блюдо»
работают и без них, но с этими плагинами сайт получает SEO, скорость,
безопасность, форму брони и два языка.

| Задача | Плагин | Зачем |
|---|---|---|
| SEO | **Rank Math SEO** | Мета-теги, sitemap.xml, Schema (Restaurant / Menu), хлебные крошки, разметка для Google. |
| Кеш и скорость | **WP Super Cache** или **LiteSpeed Cache** | Страничный кеш, сжатие, отложенная загрузка. Меню — статичный контент, кеш даёт заметный прирост. |
| Безопасность | **Wordfence Security** | Файрвол, скан на вредоносный код, ограничение попыток входа. |
| Форма брони | **Contact Form 7** (или **WPForms Lite**) | Форма «Бронь стола» с отправкой заявки на почту ресторана. См. `forma-broni.md`. |
| Два языка (RU/EN) | **Polylang** | Русская и английская версии страниц, блюд и меню; языковой переключатель. |
| Импорт демо-контента | **WordPress Importer** | Разовый импорт `wp/import/verano-demo.xml`. После импорта можно отключить. |

## Замечания по настройке

**Rank Math**
- В мастере настройки выберите тип сайта «Ресторан/Местный бизнес», заполните адрес,
  телефон, часы работы — Rank Math отдаст их в Schema для карточки Google.
- Проверьте, что архив блюд (`/menu-item/`) индексируется, а служебные страницы — нет.

**Polylang**
- Языки: Русский (по умолчанию) и English.
- Тип записи «Блюдо» и таксономию «Категории меню» включите в переводимые
  (Языки → Настройки → Custom post types & Taxonomies).
- В демо-теме уже есть визуальный переключатель RU/EN (кнопки в шапке) — он
  переключает подписи интерфейса на статических блоках. Для полноценного перевода
  всего контента используйте языковой переключатель Polylang (виджет/меню).

**Кеш**
- После правок меню очищайте кеш, иначе изменения появятся не сразу.
- Исключите из кеша страницу брони, если форма использует динамические токены.

**Wordfence**
- Включите двухфакторную авторизацию для админа и автоматические обновления
  правил файрвола.
