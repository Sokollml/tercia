# Verano — сайт средиземноморской остерии

Портфолио-проект: сайт ресторана в двух вариантах — **на WordPress** (для реального
клиента, с админкой и редактируемым меню) и **статическое демо** (HTML/CSS/JS без
сборки, разворачивается на Vercel за минуту). Дизайн, тексты и фото — «под ключ»,
двуязычный интерфейс RU/EN.

> **Демо-проект.** Verano — семейная средиземноморская остерия «с 2012 года»: домашняя
> паста, рыба из дровяной печи, сезонные овощи и локальные вина. Тёплая палитра
> (крем / терракота / олива), крупная типографика с засечками, спокойная сетка
> карточек — без «дефолтного ИИ-стайла»: никаких фиолетовых градиентов и стеклянных
> карточек. Все иконки — инлайновый SVG, фото — с Unsplash с фолбэком на локальные
> плейсхолдеры.

## Часть 1. Статическое демо (`demo/`)

Чистый HTML/CSS/JS, **без сборки и зависимостей**. Открывается двойным кликом.

### Запуск локально

Просто откройте `demo/index.html` в браузере. Для «честных» относительных путей
можно поднять локальный сервер:

```bash
cd demo
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

### Деплой на Vercel

1. Залейте репозиторий на GitHub.
2. На vercel.com → **Add New → Project** → импортируйте репозиторий.
3. **Root Directory:** укажите `01-wp-restaurant/demo` (либо `demo`, если это корень репо).
4. Framework Preset: **Other**, сборка не нужна (Output = корень).
5. Deploy. Готовый адрес впишите выше в раздел «Живое демо».

### Что уже работает в демо

- Переключатель языка **RU/EN** (JS, выбор запоминается в `localStorage`).
- Меню по 6 категориям с ценами и метками **веган / остро / выбор шефа**, фильтр.
- Галерея с **лайтбоксом** (клавиши ←/→/Esc, свайп-навигация кнопками).
- Форма брони с валидацией и сообщением об успехе (демо — заявка никуда не уходит).
- Видео — эмбед YouTube (nocookie), карта — эмбед OpenStreetMap.
- Адаптив **от 375px**, мобильное меню-бургер.
- Фото грузятся с Unsplash; если фото недоступно — автоматически подставляется
  локальный SVG-плейсхолдер (`assets/img/placeholder.svg`), вёрстка не ломается.

## Часть 2. WordPress (`wp/`)

Самостоятельная тема + mu-plugin с типом записи «Блюдо». Меню ресторана
редактируется прямо из админки, без правки кода. Тема совместима с **Elementor** —
страницы можно верстать визуально.

### Как поднять на WordPress

1. Установите WordPress (локально удобно через **LocalWP**, **XAMPP** или Docker).
2. Скопируйте тему: папку `wp/theme` → `wp-content/themes/verano`.
   Активируйте её в **Внешний вид → Темы**.
3. Скопируйте плагин: `wp/mu-plugins/verano-dish-cpt.php` →
   `wp-content/mu-plugins/` (папку `mu-plugins` создайте, если её нет).
   Он загрузится автоматически и добавит в админку раздел **«Меню (блюда)»**.
4. **Настройки → Постоянные ссылки** → нажмите «Сохранить» (чтобы заработали
   адреса блюд `/menu-item/...`).
5. Импортируйте демо-контент: **Инструменты → Импорт → WordPress**, файл
   `wp/import/verano-demo.xml`. Подробно — [`wp/docs/import-instrukciya.md`](wp/docs/import-instrukciya.md).
6. Установите рекомендованные плагины — [`wp/docs/plaginy.md`](wp/docs/plaginy.md).
7. Подключите форму брони — [`wp/docs/forma-broni.md`](wp/docs/forma-broni.md).

### Как редактировать меню через админку

1. В левом меню админки откройте **«Меню (блюда)» → «Добавить блюдо»**.
2. Заполните:
   - **Заголовок** — название блюда;
   - **Текст** — описание;
   - **Фото блюда** (Featured image, блок справа) — фотография;
   - блок **«Детали блюда»** справа — **цену** (например `₽ 890`) и **метки**
     веган / остро / выбор шефа галочками;
   - блок **«Категории меню»** — категория (Закуски, Паста, Из печи, Веган,
     Десерты, Вино и напитки).
3. Нажмите **«Опубликовать»**. Блюдо сразу появится в архиве меню, а если стоит
   метка «Выбор шефа» — ещё и в витрине на главной.
4. Категории меню добавляются/переименовываются в **«Меню (блюда) → Категории меню»**.

Цена и метки видны прямо в списке блюд (отдельные колонки), так что владельцу
удобно править меню, не заходя в каждое блюдо.

### Совместимость с Elementor

Тема не навязывает разметку контента: страницы «Главная», «О нас», «Галерея»,
«Контакты» можно полностью собрать в Elementor. Стили темы (кнопки, карточки,
секции) остаются доступными. Тип записи «Блюдо» и его архив работают независимо от
конструктора.

## Технологии

- **Демо:** семантический HTML5, современный CSS (grid/flex, кастомные свойства),
  ванильный JavaScript. Без фреймворков и сборщиков.
- **WordPress:** PHP-тема (WordPress 6.x, PHP 7.4+), Custom Post Type + Custom
  Taxonomy + мета-поля, mu-plugin, экспорт WXR 1.2.
- **Совместимость:** Elementor, Contact Form 7 / WPForms, Polylang, Rank Math.
