# AI-ассистент деловых текстов (n8n + Telegram)

> **Статус: демо-проект для портфолио.** Это готовый к импорту макет
> рабочего процесса n8n. Он показывает архитектуру и логику, но перед боевым
> запуском требует подключения ваших credentials и небольшой доводки под ваш инстанс.

## Что делает

Телеграм-бот превращает сырые тезисы в готовый деловой текст:

1. Пользователь присылает боту **тезисы обычным текстом**.
2. Бот отвечает **инлайн-кнопками формата**: ✉️ Письмо · 💬 Ответ · 📢 Пост.
3. Пользователь выбирает формат → **AI Agent** генерирует текст в нужном тоне.
4. Ответ приходит с кнопкой **🔁 «Другой вариант»** — она перегенерирует текст
   по последнему сохранённому запросу (тезисы + формат берутся из БД).

Язык ответа (RU/EN) определяется автоматически по языку клиента Telegram.
Каждая генерация пишется в лог и учитывается в **дневном лимите** (демо-монетизация).

## Схема процесса

```
[ Telegram Trigger ]
        │
        ▼
[ Switch: тип апдейта ]───────────────┐
        │ message                     │ callback_query
        ▼                             ▼
[ Code: Клавиатура форматов ]   [ Code: Разбор callback ]
        │                             │
        ▼                             ▼
[ Postgres: Сохранить тезисы ]  [ Postgres: Лимит + последний запрос ]
        │                             │
        ▼                             ▼
[ Telegram: Показать форматы ]  [ IF: Лимит не превышен? ]
                                  │ true            │ false
                                  ▼                 ▼
                            [ AI Agent ]      [ Telegram: сообщение о лимите ]
                          (OpenAI Chat Model
                           через ai_languageModel)
                                  │
                                  ▼
                        [ Telegram: Ответ + кнопка «Другой вариант» ]
                                  │
                                  ▼
                        [ Postgres: Лог использования ]
```

## Импорт в n8n

У вас уже есть n8n на VPS (Docker + Postgres) — **свой поднимать не нужно**.

1. В интерфейсе n8n: **Workflows → ⋮ → Import from File** → выберите
   `workflows/text_assistant.json`.
2. Примените SQL-схему к вашей базе Postgres:
   ```bash
   docker exec -i <postgres_container> psql -U <user> -d <db> < db/001_usage.sql
   ```
3. Проставьте credentials на нодах (см. ниже) — после импорта они не привязаны.
4. Откройте ноды-промпты при желании подправьте тон под себя (`prompts/text_formats.txt`).
5. Включите workflow (**Active**) — Telegram Trigger сам зарегистрирует webhook.

## Необходимые credentials

| Нода | Тип credential | Что нужно |
|------|----------------|-----------|
| Telegram Trigger, Показать форматы, Ответ + кнопка, Сообщение о лимите | **Telegram API** | Bot Token от @BotFather |
| OpenAI Chat Model | **OpenAI** (LLM) | API-ключ; модель по умолчанию `gpt-4o-mini` (можно заменить на любой LLM-нод) |
| Сохранить тезисы, Лимит и последний запрос, Лог использования | **Postgres** | доступ к вашей БД на VPS |

## Настройка бота (@BotFather)

1. Откройте **@BotFather** → `/newbot` → задайте имя и username.
2. Скопируйте **Bot Token** → вставьте в Telegram credential в n8n.
3. Рекомендуется `/setprivacy` → **Disable**, чтобы бот видел все сообщения (для групп).
4. Опционально `/setcommands`:
   ```
   start - как пользоваться
   ```

## Дневной лимит (демо-монетизация)

- Лимит на пользователя в сутки задаётся переменной окружения n8n **`DAILY_LIMIT`**
  (по умолчанию `10`, читается в ноде «Лимит и последний запрос» как `$vars.DAILY_LIMIT`).
- Счётчик — это `COUNT(*)` из `ta_usage` за `CURRENT_DATE`.
- При достижении лимита нода **IF** уводит поток в «Сообщение о лимите» вместо генерации.
- Идея монетизации: бесплатно N текстов в день, дальше — платный план
  (снять лимит / поднять `DAILY_LIMIT` для «премиум» user_id).

## Чек-лист запуска

- [ ] SQL-схема применена (`ta_usage`, `ta_last_request` существуют).
- [ ] Telegram credential создан, Bot Token от @BotFather вставлен.
- [ ] OpenAI (или другой LLM) credential подключён к «OpenAI Chat Model».
- [ ] Postgres credential выбран на всех трёх Postgres-нодах.
- [ ] Переменная `DAILY_LIMIT` задана (или устраивает дефолт 10).
- [ ] Workflow импортирован и переключён в **Active**.
- [ ] Проверка: прислать боту тезисы → появились кнопки форматов.
- [ ] Проверка: выбрать формат → пришёл текст + кнопка «Другой вариант».
- [ ] Проверка: нажать «Другой вариант» → пришёл иной вариант того же формата.
- [ ] Проверка: превысить лимит → пришло сообщение о лимите.

## Заметки по доводке (честно про ограничения)

- Выражения в Postgres-нодах используют `queryReplacement` — при первом запуске
  проверьте, что порядок параметров совпадает с `$1..$N` в запросах.
- `ai_languageModel` подключён как sub-нода к AI Agent; при желании замените OpenAI
  на любой другой LLM-нод, сохранив тип соединения.
- Многопользовательский regen хранит **один последний запрос на user_id** —
  для истории вариантов расширьте `ta_last_request` до отдельной таблицы версий.
