# FORMA — установка и импорт (WordPress-часть)

Инструкция по разворачиванию темы, mu-плагина и демо-контента.

## 1. Требования
- WordPress 6.0+
- PHP 7.4+
- MySQL/MariaDB

## 2. Установка темы и ядра
1. Скопируйте папку `wp/themes/forma-fitness/` в `wp-content/themes/`.
2. Скопируйте `wp/mu-plugins/forma-core.php` в `wp-content/mu-plugins/`
   (если папки `mu-plugins` нет — создайте её). mu-плагины активируются автоматически.
3. В админке: **Внешний вид → Темы → FORMA Fitness → Активировать**.
4. После активации один раз зайдите в **Настройки → Постоянные ссылки** и нажмите
   «Сохранить» — это обновит ЧПУ для `/schedule/` и `/trainers/`.

> Тема самостоятельная (родительская не нужна). Чтобы использовать её как child-тему Astra:
> установите и активируйте Astra, в шапке `style.css` темы добавьте строку
> `Template: astra`, затем активируйте FORMA как дочернюю.

## 3. Импорт демо-контента
1. **Инструменты → Импорт → WordPress** (установите импортёр, если предложат).
2. Загрузите файл `wp/sample-content/forma-sample.xml`.
3. Назначьте автора и запустите импорт.
4. Импортируются: 4 тренера, 8 занятий, термины таксономии «Тип тренировки».

### Важно: связка «Занятие → Тренер»
Мета-поле `_forma_trainer_id` хранит ID тренера, а при импорте WordPress выдаёт
**новые ID**. Поэтому после импорта:
1. Откройте **Расписание → Все занятия**.
2. В каждом занятии справа в блоке **«Детали занятия»** выберите тренера из списка
   и обновите запись. Это 2–3 минуты на все занятия.

Фотографии тренеров в XML не входят (чтобы файл был лёгким). Добавьте их вручную:
**Тренеры → выбрать тренера → «Изображение записи»**. Портрет 3:4, ~500×667.

## 4. Как устроена админка (управление контентом)
- **Расписание (тип «Занятие», `class`)**: заголовок = название занятия,
  блок «Детали занятия» = день недели, время, тренер; блок «Типы» = тип тренировки
  (Сила / Кардио / Тело и ум / Танцы). Добавили занятие → оно сразу в сетке.
- **Тренеры (тип «Тренер», `trainer`)**: заголовок = имя, «Изображение записи» = фото,
  основной текст = био, поле «Специализация» = подпись под именем.

## 5. Вывод на страницах
Шорткоды (работают в редакторе и в Elementor через виджет «Шорткод»):
- `[forma_schedule]` — сетка расписания по дням.
- `[forma_trainers]` — карточки тренеров.

Готовые архивы доступны по адресам `/schedule/` и `/trainers/`
(шаблоны `archive-class.php`, `archive-trainer.php`).

## 6. Рекомендуемые страницы
Создайте страницы и назначьте главную (**Настройки → Чтение → Статическая главная**):
- **Главная** — Elementor или встроенный `front-page.php`.
- **Расписание** — со `[forma_schedule]` (или ссылка на `/schedule/`).
- **Тренеры** — с `[forma_trainers]` (или ссылка на `/trainers/`).
- **Тарифы** — блоки + форма заявки.
- **Контакты** — карта + форма пробного занятия.

## 7. Форма заявки (заявка → email)
Вариант A — **Contact Form 7**: создайте форму (Имя, Телефон, Направление, Комментарий),
в письме укажите почту студии, вставьте шорткод формы на страницы «Тарифы»/«Контакты».

Вариант B — **WPForms Lite**: шаблон «Simple Contact Form», настройте
**Settings → Notifications** на адрес студии.

Для доставки писем поставьте SMTP-плагин (**WP Mail SMTP**), иначе часть писем уходит в спам.

## 8. Рекомендуемые плагины
| Задача | Плагин |
|---|---|
| Мультиязычность RU/EN | **Polylang** |
| SEO (мета, sitemap, schema) | **Rank Math** |
| Формы заявок | **Contact Form 7** или **WPForms Lite** |
| Доставка почты | **WP Mail SMTP** |
| Кеш/скорость | **WP Super Cache** или **LiteSpeed Cache** |
| Безопасность | **Wordfence Security** |
| Конструктор страниц | **Elementor** |

### Polylang (RU/EN)
1. **Языки → Языки**: добавьте Русский (по умолчанию) и English.
2. Переведите занятия и тренеров: у каждой записи появится колонка флагов —
   создайте английскую версию.
3. Строки интерфейса темы: **Языки → Переводы строк** (тема регистрирует их через
   `pll_register_string`, см. `functions.php`).
4. Переключатель языка тема выводит в шапке автоматически (`pll_the_languages`).
