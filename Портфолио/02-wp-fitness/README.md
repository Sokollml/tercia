# FORMA — сайт фитнес-студии

Демонстрационный сайт для студии функционального фитнеса. Проект показывает
два подхода к одному и тому же продукту:

- **`wp/`** — полноценный сайт на **WordPress**, где расписание и тренеры управляются
  из админки (кастомные типы записей, мета-поля, шорткоды, Elementor, Polylang RU/EN).
- **`demo/`** — статическая демо-версия (HTML/CSS/JS без сборщика), которую можно
  за минуту выложить на Vercel/Netlify и показать заказчику.

> Это демо для портфолио: тексты, цены, адрес и фото — демонстрационные.

## Демо-версия (`demo/`)

Чистый статический сайт: **без сборщика, без зависимостей**.

- 5 страниц, общий хедер/футер, адаптив **от 375px**.
- **Переключатель языка RU/EN** на чистом JS (`assets/js/main.js`, выбор сохраняется
  в `localStorage`).
- **Сетка расписания** строится из одного источника данных: на десктопе — таблица
  день×время, на мобильном — карточки по дням. Есть фильтр по типу тренировки.
- **Формы** (заявка, пробное) с клиентской валидацией и сообщением об успехе
  (без бэкенда — это демо).
- Дизайн намеренно **не «дефолтный ИИ»**: лаймовый акцент на светлом фоне,
  inline-SVG иконки, никаких фиолетовых градиентов и «стеклянных» карточек.
- Фото — с Unsplash, при недоступности подставляются локальные SVG-плейсхолдеры.

### Локальный просмотр
Просто откройте `demo/index.html` в браузере. Либо поднимите любой статический сервер:

```bash
cd demo
python3 -m http.server 5173
# http://localhost:5173
```

### Деплой на Vercel
Корень проекта — папка `demo/` (Framework preset: **Other**, сборка не нужна).
Или через CLI: `cd demo && vercel`.

## WordPress-версия (`wp/`)

Сайт, которым управляет администратор без кода.

- **Тип «Занятие» (`class`)** — расписание: день недели, время, тренер, тип тренировки
  (таксономия). Тип, день и время задаются в мета-боксе; в списке занятий есть колонки
  «День» и «Время».
- **Тип «Тренер» (`trainer`)** — имя (заголовок), фото (изображение записи),
  специализация (поле), био (текст).
- Регистрация типов и мета вынесена в **mu-plugin** — данные не теряются при смене темы.
- Вывод: шорткоды `[forma_schedule]` и `[forma_trainers]` (работают и в Elementor),
  плюс готовые архивы `/schedule/` и `/trainers/`.
- **Polylang** для RU/EN, **Rank Math** для SEO, форма заявки на **CF7/WPForms → email**,
  кеш и безопасность — см. таблицу плагинов в инструкции.

### Управление расписанием через админку
1. **Расписание → Добавить занятие**.
2. Вписать название, выбрать день, время и тренера (блок «Детали занятия»),
   отметить тип (блок «Типы»).
3. Опубликовать — занятие сразу появляется в сетке `[forma_schedule]` и на `/schedule/`.

Полная инструкция по установке, импорту демо-контента и плагинам:
**[`wp/docs/import-instructions.md`](wp/docs/import-instructions.md)**.
