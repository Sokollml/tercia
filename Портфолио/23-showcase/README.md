# Tercia — витрина портфолио

![Витрина](docs/preview.png)

Одностраничная витрина агентства **в точности в дизайне [tercia.dev](https://tercia.dev)**: тот же хедер, hero, услуги, цифры, процесс, футер и контакты — плюс новая секция **«Кейсы»** с 22 работами (у каждой кнопки «Живое демо» и «GitHub»).

Дизайн-система (`styles.css`) и фавикон взяты с боевого сайта дословно — витрина выглядит как родная страница tercia.dev. Секция кейсов использует уже заложенные в их CSS классы `.cases`/`.case`, которых на самом сайте пока не было.

## Стек
Чистый статический сайт — **HTML + CSS + JS**, без сборщика. Шрифты Space Grotesk + Manrope (Google Fonts). Языки RU / EN / 中 (движок i18n в `script.js`). Тёмная тема, как на оригинале.

```
23-showcase/
├── index.html        # разметка (хедер/hero/кейсы/услуги/цифры/процесс/CTA/футер)
├── styles.css        # дизайн-система tercia.dev (дословно)
├── showcase.css      # +несколько правил под сетку кейсов (на тех же токенах)
├── script.js         # i18n RU/EN/中 + рендер 22 кейсов + меню
└── assets/favicon.svg
```

## Запуск локально
```bash
cd "23-showcase" && python3 -m http.server 8099
# открыть http://localhost:8099
```
(или просто открыть `index.html` в браузере).

## Как вписать ссылки на демо и GitHub
Все 22 карточки описаны массивом `CASES` в начале `script.js`. У каждой — поля `demo` и `repo` (сейчас `'#'` → кнопка показывается как «Живое демо · скоро»). Впиши реальные ссылки:
```js
{ cat: 'landing', cover: 1,
  demo: 'https://landings.tercia.dev/saas',   // ← Vercel
  repo: 'https://github.com/tercia/…',        // ← GitHub
  title: { ru: 'SaaS-аналитика — Swiss', … }, … }
```
Как только `demo`/`repo` != `'#'`, кнопка становится активной ссылкой.

## Деплой на Vercel
Статичный сайт, сборка не нужна:
1. Залить папку в отдельный GitHub-репозиторий.
2. vercel.com → Add New Project → выбрать репо → Framework preset: **Other** → Deploy.
3. Привязать домен (например, `tercia.dev` или `portfolio.tercia.dev`) в настройках проекта.

CLI-вариант:
```bash
npm i -g vercel && cd "23-showcase" && vercel --prod
```
