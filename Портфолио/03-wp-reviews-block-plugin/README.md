# Reviews Block — блок отзывов для Gutenberg

Плагин для WordPress, который добавляет кастомный тип записи **«Отзыв»** (testimonial)
и Gutenberg-блок для вывода отзывов **каруселью** или **сеткой**. Без сборщика,
без тяжёлых зависимостей, i18n-ready (RU/EN).

## Демо

Живая статическая демонстрация карусели и сетки (переключение вида, автопрокрутка,
адаптив, RU/EN):

**[Открыть демо](https://reviews-block-demo.vercel.app)** ← замените на свой Vercel-URL

Локально демо лежит в папке [`demo/index.html`](demo/index.html) — это standalone
HTML/JS без сборки, открывается двойным кликом.

## Идея

Идея: дать редактору сайта простой способ собирать «социальное доказательство»
(social proof) без сторонних SaaS-виджетов и рекламных скриптов.

- Отзывы — это обычные записи, значит работают привычные черновики, права доступа,
  поиск и REST API.
- Блок — **динамический**: HTML рендерится на PHP в момент запроса, поэтому свежие
  отзывы появляются без пересохранения страницы.
- Фронтенд-скрипт карусели написан на чистом JS (нативный `scroll-snap`), уважает
  `prefers-reduced-motion` и не тянет jQuery/Swiper.
- Внешний вид меняется через CSS-переменные — легко подогнать под тему.

## Возможности

- Кастомный тип записи «Отзыв»: имя автора (заголовок), текст (контент),
  фото (featured image), оценка 1–5 и компания/должность (мета-поля).
- Gutenberg-блок `reviews-block/testimonials` с атрибутами:
  - `count` — количество отзывов (1–24);
  - `layout` — `carousel` или `grid`;
  - `autoplay` — автопрокрутка карусели;
  - `interval` — интервал автопрокрутки, мс.
- Панель настроек блока в редакторе + предпросмотр через `ServerSideRender`.
- Экранирование и санитайзинг на всех входах/выходах, проверка nonce и прав.
- Готово к переводу: `load_plugin_textdomain`, `.pot`, перевод `en_US`.
- Адаптивная вёрстка (до 375px), рейтинг inline-SVG-звёздами.

## Установка

### Вариант 1. Загрузка ZIP через админку

1. Соберите/возьмите архив `build/reviews-block.zip`.
2. В админке WordPress: **Плагины → Добавить новый → Загрузить плагин**.
3. Выберите `reviews-block.zip`, нажмите **Установить**, затем **Активировать**.

### Вариант 2. Вручную

1. Скопируйте папку `plugin/` в `wp-content/plugins/` и переименуйте в `reviews-block`.
2. Активируйте плагин на странице **Плагины**.

### После активации

1. В меню админки появится раздел **«Отзывы»** — добавьте несколько записей
   (имя в заголовок, текст в контент, оценку и компанию — в блоке «Детали отзыва»,
   фото — через «Изображение записи»).
2. На любой странице/записи добавьте блок **«Отзывы (Reviews)»** и настройте
   количество, вид и автопрокрутку в панели справа.

**Требования:** WordPress 6.1+, PHP 7.4+.

```
│   │   ├── editor.js            # редактор блока (plain JS, без JSX/сборки)
│   │   ├── editor.asset.php     # ручной манифест зависимостей editor.js
│   │   ├── editor.css           # стили предпросмотра в редакторе
│   │   ├── frontend.js          # карусель на фронте (vanilla JS)
│   │   └── frontend.css         # адаптивные стили блока
│   └── languages/
│       ├── reviews-block.pot         # шаблон перевода
│       └── reviews-block-en_US.po    # английский перевод
├── demo/
│   └── index.html              # standalone-демо для Vercel
├── build/
│   └── reviews-block.zip        # готовый архив плагина для загрузки в WP
├── README.md
└── .gitignore
```

## Разработка

Плагин намеренно не требует Node/сборки: редакторный скрипт написан на чистом
`wp.element.createElement`, зависимости объявлены в `editor.asset.php`.

Пересобрать ZIP из папки `plugin/`:

```bash
cd 03-wp-reviews-block-plugin
rm -f build/reviews-block.zip
( cd plugin && zip -r ../build/reviews-block.zip . -x '.*' -x '**/.*' )
```
