# Community Engagement Bot

Telegram-бот для вовлечённости в групповых чатах: встречает новичков, начисляет
очки (XP) за активность с защитой от абьюза, ведёт уровни и ранги, строит
лидерборды за неделю и за всё время, автоматически публикует недельный топ и
«вопрос дня»/опросы по расписанию, награждает за стрики и повышение ранга.

Стек: **aiogram 3**, **SQLAlchemy 2 (async)**, **PostgreSQL** в проде и
**SQLite** локально, **APScheduler** для расписаний. Интерфейс двуязычный:
**русский / английский**.

## Что умеет бот

- **Приветствие новичков** — настраиваемый текст (плейсхолдер `{name}`), можно
  включать/выключать на чат.
- **XP за сообщения с анти-абьюзом:**
  - кулдаун между начислениями (по умолчанию 60 сек);
  - антифлуд-окно (быстрые подряд сообщения не считаются);
  - минимальная длина сообщения;
  - игнор команд (`/...`) и стикеров/GIF.
- **Уровни и ранги** — кривая уровней по накопленному XP, ранги: Новичок →
  Активный → Знаток → Ветеран → Легенда.
- **Стрики** — счётчик дней подряд с активностью, бейдж за вехи (3, 7, 14, 30,
  60, 100 дней).
- **Команды участников:**
  - `/me` — карточка: очки, ранг, уровень, стрик, место в чате;
  - `/top` — лидерборд за неделю и за всё время;
  - `/rank` — таблица рангов;
  - `/help` — справка.
- **Автопостинг по расписанию:**
  - «вопрос дня» или опрос из пула;
  - недельный топ с поздравлением лидеров.
- **Награды** — уведомления о повышении уровня/ранга и о достижении вехи стрика.

## Команды администратора

Доступны админам чата и глобальным админам из `ADMIN_IDS`.

| Команда | Действие |
|---|---|
| `/settings` | показать текущие настройки чата |
| `/set <ключ> <значение>` | изменить настройку |
| `/toggle <модуль>` | вкл/выкл модуль |
| `/setwelcome <текст>` | задать приветствие (`{name}` подставит имя) |
| `/lang ru\|en` | язык чата |
| `/prompt` | опубликовать «вопрос дня» прямо сейчас |

Модули для `/toggle`: `welcome`, `xp`, `leaderboard`, `daily`.

Ключи для `/set`:

| Ключ | Что настраивает | Диапазон |
|---|---|---|
| `xp_per_message` | очков за сообщение | 1–1000 |
| `cooldown` | кулдаун между начислениями, сек | 0–86400 |
| `min_len` | мин. длина сообщения | 0–500 |
| `antiflood` | антифлуд-окно, сек | 0–600 |
| `prompt_time` | время «вопроса дня», `ЧЧ:ММ` | — |
| `weekly_time` | время недельного топа, `ЧЧ:ММ` | — |

## Как добавить бота в чат и выдать права

1. Создайте бота у [@BotFather](https://t.me/BotFather), получите `BOT_TOKEN`.
2. В настройках бота у BotFather **отключите Group Privacy**
   (`/setprivacy` → `Disable`). Без этого бот не видит обычные сообщения и не
   сможет начислять XP.
3. Добавьте бота в группу и **назначьте его администратором** — минимально нужны
   права: удаление сообщений не требуется, но нужны права на чтение сообщений
   участников (даёт статус админа) и на отправку сообщений/опросов.
4. Напишите `/help` в чате, чтобы проверить, что бот отвечает.
5. Настройте модули и тексты командами администратора (см. выше).

> Приватность: при отключённом Group Privacy бот получает все сообщения чата,
> чтобы считать активность. Он хранит только XP/уровни/стрики и агрегаты, не
> содержимое сообщений. Учитывайте это и предупредите участников.

## Запуск локально (SQLite)

Требуется Python 3.9+.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
# впишите BOT_TOKEN в .env (DB_ENGINE=sqlite уже по умолчанию)

python -m bot.main
```

База SQLite создастся автоматически в `data/bot.db`, таблицы и стартовый пул
вопросов заполнятся при первом запуске.

## Запуск в Docker (PostgreSQL)

```bash
cp .env.example .env
# впишите BOT_TOKEN; остальное можно оставить по умолчанию

docker compose up -d --build
```

`docker-compose.yml` поднимает два сервиса: `bot` (образ `python:3.12-slim`) и
`db` (`postgres:16`). Схема применяется из каталога `db/` при первой инициализации
базы, приложение также умеет создавать таблицы само.

## Конфигурация (`.env`)

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | токен от BotFather | — |
| `ADMIN_IDS` | глобальные админы через запятую | пусто |
| `DEFAULT_LANG` | язык новых чатов, `ru`/`en` | `ru` |
| `DB_ENGINE` | `sqlite` или `postgres` | `sqlite` |
| `DB_PATH` | путь к файлу SQLite | `data/bot.db` |
| `DB_HOST` / `DB_PORT` / `DB_NAME` / `DB_USER` / `DB_PASSWORD` | параметры PostgreSQL | см. `.env.example` |
| `TZ` | таймзона расписаний | `Europe/Amsterdam` |
| `LOG_LEVEL` | уровень логов | `INFO` |

Полный список — в [`.env.example`](.env.example).

## Тесты

Покрыты: начисление XP с кулдауном и анти-абьюзом, расчёт уровня/ранга по XP,
недельный и общий лидерборд.

## Структура проекта

```
bot/
  config.py            конфиг из .env
  db.py                модели SQLAlchemy (chats, members, daily_prompts, events)
  i18n.py              строки RU/EN
  xp.py                чистая логика XP/уровней/стриков (без aiogram и БД)
  middlewares.py       сессия БД в каждый хендлер
  scheduler.py         APScheduler: вопрос дня + недельный топ
  main.py              точка входа
  handlers/            commands, admin, members (welcome), messages (XP)
  services/            members, leaderboard, prompts
db/                    SQL-миграции и сид для PostgreSQL
tests/                 pytest (XP, уровни, лидерборд)
docs/                  GIF и скриншоты для README
```
