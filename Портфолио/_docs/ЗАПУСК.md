## 1. Что делаете ВЫ, а что автоматизируется

Три вещи по правилам безопасности вписываете **только вы** (я не ввожу токены/ключи):
1. **Токены ботов** — создаёте бота у [@BotFather](https://t.me/BotFather), кладёте токен в `.env` проекта на сервере.
2. **LLM-ключ** (OpenAI или совместимый) — в n8n credentials и в `.env` ботов, где есть ИИ.
3. **Аккаунт Vercel** — деплой жмёте вы (или даёте `vercel` CLI-токен).

Всё остальное — сборка образов, создание БД в Postgres, Caddy-роуты, запуск контейнеров, импорт n8n-JSON — по SSH/скриптами.

## 3. n8n-проекты (09, 10, 11, 20, 21, 22) → импорт в ваш n8n

Одинаковый порядок для каждого:

1. **Накатить SQL** на Postgres VPS. Пример (из папки проекта):
   ```bash
   scp "…/09-n8n-nutritionist/db/001_nutrition.sql" ubuntu@158.160.214.116:/tmp/
   ssh -l ubuntu 158.160.214.116 'docker exec -i n8n-postgres-1 psql -U n8n -d n8n < /tmp/001_nutrition.sql'
   ```
   > Можно держать всё в одной БД `n8n` (таблицы с префиксами) — под ваш маленький сервер это разумно и без новых контейнеров.
2. **Создать credentials** в n8n (Settings → Credentials): Telegram Bot API, LLM (OpenAI/совместимый), Postgres (host `postgres`, port `5432`, db `n8n`, user `n8n`, пароль из `~/n8n/.env`).
3. **Импорт воркфлоу:** в n8n → Workflows → «Import from File» → выбрать `workflows/*.json`.
4. **Привязать credentials** в нодах (при первом открытии ноды n8n предложит выбрать), проверить модель LLM.
5. **Промпт** из `prompts/*.txt` уже внутри ноды AI Agent — при желании поправить.
6. **Save → Active.** Для ботов: создать бота у @BotFather, токен вписать в Telegram-credential.

Детали и чек-лист прогона — в README каждого проекта.

## 4. Telegram-боты кодом (08, 12, 13, 14, 15, 16) → VPS

Каждый бот — свой docker-compose (бот + при желании отдельный postgres, но лучше переиспользовать общий). Быстрый путь на ваш сервер, **переиспользуя существующий Postgres**:

1. Создать отдельную БД под бота (один раз):
   ```bash
   ssh -l ubuntu 158.160.214.116 'docker exec -i n8n-postgres-1 psql -U n8n -d n8n -c "CREATE DATABASE bot_booking;"'
   ```
2. Скопировать проект на сервер:
   ```bash
   rsync -av --exclude node_modules --exclude .venv "…/08-bot-booking/" ubuntu@158.160.214.116:~/bots/08-bot-booking/
   ```
3. Заполнить `.env` (на сервере) — `BOT_TOKEN` от @BotFather, `DB_*` на общий Postgres (`postgres:5432`, БД `bot_booking`), `MASTER_IDS`/`ADMIN_IDS`.
4. Накатить миграции (`db/*.sql`) в БД бота (как в п.3.1).
5. Поднять контейнер в общей сети n8n (чтобы видеть `postgres`):
   ```bash
   cd ~/bots/08-bot-booking && docker compose up -d --build
   # если compose поднимает свой postgres — можно убрать его и указать сеть n8n_default (см. README бота)
   ```
6. **Боты сообществ (13–16):** добавить бота в тестовый чат, дать **админ-права**, у @BotFather выключить **privacy mode** (иначе бот не видит сообщения). Показывать вживую в тестовом чате.

> Режим `polling` вебхук/домен не требует — для демо это проще всего.

## 5. Mini-apps (17, 18, 19) → фронт Vercel + бэк VPS

1. **Бэкенд** на VPS: как бот (п.4), но нужен HTTPS-домен для API — добавить поддомен в Caddy:
   ```
   # ~/n8n/Caddyfile — добавить блок:
   habits-api.tercia.dev {
       reverse_proxy habits-backend:PORT
   }
   ```
   затем `docker exec n8n-caddy-1 caddy reload --config /etc/caddy/Caddyfile` (или перезапуск caddy). DNS-запись `*.tercia.dev` → IP сервера.
2. **Фронт** mini-app → Vercel (как лендинги). В `.env` фронта прописать URL API (`habits-api.tercia.dev`).
3. **Бот-лаунчер:** у @BotFather задать кнопку Web App (Menu Button / `/setmenubutton`) с URL фронта на Vercel.
4. **19 (поиск заказов):** сначала поднять как **личный инструмент** (вы — единственный пользователь). Collector = Telethon userbot: **отдельный аккаунт/номер**, только чтение, троттлинг. `api_id`/`api_hash` — на my.telegram.org. Сессия Telethon в volume, не в репозиторий. Классификация и API — n8n-воркфлоу (импорт как в п.3).

## 7. Как показывать заказчику (важнее кода)

1. **GIF/скрин в первом экране README** — заказчик смотрит, а не читает код. Запишите короткий экранкаст (QuickTime / [Kap](https://getkap.co)) и положите в `docs/demo.gif` каждого проекта.
2. **Живые ссылки:** лендинги/витрина/mini-app фронты — Vercel; боты — `t.me/ваш_бот` прямо в переписку.
3. **Тестовый чат** для ботов сообществ — покажите welcome, начисление XP, лидерборд, викторину вживую.
4. **GitHub:** каждый проект — отдельный репозиторий, Pin в профиле, добавить topics и ссылку на демо в описание. Витрина (23) собирает всё в одну страницу.
5. **Честность:** в демо данные вымышленные. Реальные заказы → заменяйте на настоящие кейсы с разрешения клиента.
