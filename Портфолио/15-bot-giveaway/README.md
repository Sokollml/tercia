# 🎁 Giveaway Bot — Telegram-бот розыгрышей для сообществ

Бот для проведения честных розыгрышей в Telegram-чатах и каналах: приз,
условия, дедлайн, участие в один клик, реферальная механика и **проверяемый**
случайный выбор победителей.

## Что делает

- **Создание розыгрыша администратором** — приз, число победителей, время до
  завершения и (опционально) канал для обязательной подписки.
- **Участие в один клик** — инлайн-кнопка «🎉 Участвую» под постом.
- **Условие подписки на канал** — проверяется через `get_chat_member`; без
  подписки участие не засчитывается.
- **Реферальная механика** — у каждого участника своя deep-link
  (`https://t.me/<bot>?start=g<ID>_r<user_id>`). За каждого приведённого друга
  начисляются дополнительные шансы (билеты).
- **Честный выбор победителей** — детерминированный алгоритм с **сохраняемым
  seed**. Seed фиксируется при создании розыгрыша и публикуется вместе с
  итогами, поэтому любой может перепроверить результат.
- **Автозавершение** — APScheduler сам подводит итоги, когда время вышло, и
  объявляет победителей в чат.
- **Статистика и список участников** — команды для администратора.
- **Защита от накрутки** — один аккаунт = одно участие (UNIQUE в БД);
  само-приглашения и повторные рефералы игнорируются.
- **RU/EN**, логирование, обработка ошибок, rate-limit (анти-спам).

### Как устроена честность (проверяемость)

Победители выбираются алгоритмом взвешенной выборки без возвращения
(Efraimidis–Spirakis) поверх ГПСЧ, инициализированного из `sha256(seed)`.
Участники обрабатываются в каноническом порядке (сортировка по `user_id`),
поэтому порядок строк в БД не влияет на исход. При одинаковых `seed` и списке
участников результат **всегда одинаков** — это и есть воспроизводимость.
Функция `logic.verify_draw(...)` пересчитывает розыгрыш и сверяет победителей.

## Стек

- **aiogram 3** — Telegram Bot API
- **PostgreSQL** (прод) / **SQLite** (локально) — выбор через `.env`
- **APScheduler** — автозавершение розыгрышей
- Локально Python **3.9**; в Docker `python:3.12-slim`

### Структура

```
bot/
  __main__.py     — точка входа (python -m bot)
  config.py       — конфигурация из .env
  db.py           — async-слой БД (SQLite + PostgreSQL)
  logic.py        — чистая логика: seed, выбор победителей, рефералы, deep-link
  services.py     — связка БД + Telegram API + logic (проверка подписки, розыгрыш)
  scheduler.py    — APScheduler: автозавершение
  middlewares.py  — rate-limit
  keyboards.py    — инлайн-клавиатуры
  i18n.py         — тексты RU/EN
  handlers/
    admin.py        — /new_giveaway, /stats, /participants, /finish
    participant.py  — /start (deep-link), кнопки «Участвую» и реф-ссылка
db/
  schema.sql         — схема PostgreSQL
  schema_sqlite.sql  — схема SQLite
tests/              — pytest (логика, БД, воспроизводимость seed)
```

## Использование

Команды администратора (доступны только ID из `ADMIN_IDS`):

| Команда | Описание |
|---|---|
| `/new_giveaway <приз> \| <победителей> \| <часов> \| <@канал или ->` | Создать розыгрыш и опубликовать пост с кнопкой |
| `/stats` | Статистика текущего розыгрыша (участники, рефералы, seed) |
| `/participants` | Список участников |
| `/finish` | Принудительно подвести итоги досрочно |

Пример:

```
/new_giveaway iPhone 15 | 2 | 48 | @my_channel
```

Розыгрыш на 48 часов, 2 победителя, обязательная подписка на `@my_channel`.

Для участников:

- `/start` — приветствие и кнопка «🎉 Участвую».
- Кнопка **«🎉 Участвую»** — вход в розыгрыш (с проверкой подписки).
- Кнопка **«🔗 Моя реф-ссылка»** — персональная ссылка для приглашений;
  за каждого пришедшего по ней друга — доп. шансы.

> Бот должен быть **администратором** чата, где публикуется пост, и
> администратором канала, подписку на который он проверяет.

## Деплой (Docker)

`docker-compose.yml` поднимает бота вместе с PostgreSQL:

```bash
cp .env.example .env      # заполните BOT_TOKEN и ADMIN_IDS
docker compose up -d --build
docker compose logs -f bot
```

Compose переопределяет `DB_ENGINE=postgres` и параметры подключения к
контейнеру `db`, поэтому в `.env` достаточно указать токен и админов.

Для запуска только контейнера бота (со своей внешней БД) используйте
`Dockerfile` и передайте переменные окружения напрямую.

## Конфигурация (`.env`)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `BOT_TOKEN` | — | Токен от @BotFather (обязательно) |
| `ADMIN_IDS` | — | ID администраторов через запятую |
| `DB_ENGINE` | `sqlite` | `sqlite` или `postgres` |
| `DB_PATH` | `giveaway.db` | Путь к файлу SQLite |
| `DB_DSN` / `DATABASE_URL` | — | Полный DSN PostgreSQL |
| `DB_HOST/PORT/NAME/USER/PASSWORD` | — | Параметры PostgreSQL по частям |
| `TZ` | `UTC` | Таймзона планировщика |
| `DEFAULT_LANG` | `ru` | Язык по умолчанию (`ru`/`en`) |
| `RATE_LIMIT_SECONDS` | `0.7` | Анти-спам: пауза между действиями |
| `LOG_LEVEL` | `INFO` | Уровень логирования |

Полный список — в `.env.example`.
