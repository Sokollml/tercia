# Tercia — landing page

Одностраничный лендинг IT-агентства полного цикла **Tercia**, реализованный из дизайна
`Tercia Landing.dc.html` (Claude Design). Тёмная тема, акцент — кислотно-зелёный `#D3FB52`
и фиолетовый `#7C3AED`. Шрифты: Space Grotesk (заголовки) + Manrope (текст).

Дизайн-макет показывал десктоп (1440px) и мобайл (400px) рядом; здесь это одна
адаптивная страница, которая перетекает от мобильной раскладки к десктопной.

## Структура

```
index.html      разметка страницы (все секции)
styles.css      стили, палитра в CSS-переменных, адаптив, анимации
script.js       мобильное меню (бургер), год в футере
assets/
  favicon.svg   логотип-искра
```

## Секции

Хедер (sticky) · Hero · бегущая строка · Услуги (bento-сетка) · Полоса цифр ·
Процесс (4 шага) · Кейсы · Отзыв · Финальный CTA · Футер.

## Запуск

Статический сайт — любой веб-сервер подойдёт:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## Адаптив (брейкпоинты)

- `> 1024px` — полная десктопная bento-сетка (6 колонок)
- `≤ 1024px` — сетки в 2 колонки
- `≤ 860px` — навигация сворачивается в бургер-меню
- `≤ 560px` — одноколоночная раскладка

Учитывается `prefers-reduced-motion` (отключает бегущую строку и плавающие искры).
