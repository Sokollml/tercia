# Материалы Tercia

В этой папке храним новые материалы Tercia для передачи партнёру через GitHub. Готовые файлы и ссылки в этом списке обновляем вместе. Изменения рабочего сайта и результаты проверки на домене отмечаем отдельно от демонстраций.

## Демо для первых обращений

| Компания | Файлы | Что показать |
| --- | --- | --- |
| ПеретяжкА | [Демо](demos/peretyazhka/index.html) · [скриншот](screenshots/peretyazhka.png) | Оценка по фото от формы до экрана мастера. |
| Стелла | [Демо](demos/stella/index.html) · [скриншот](screenshots/stella.png) | Запрос на запись, подтверждение времени и согласование ответа на отзыв. |
| Лама рядом | [Демо](demos/lama/index.html) · [скриншот](screenshots/lama.png) | Срочный звонок, плановая запись и назначение ответственного за отзыв. |
| Te Amo Beauty Studio | [Демо](demos/teamo/index.html) · [скриншот](screenshots/teamo.png) | Выбор услуги и мастера, переход к записи через Яндекс и источник перехода. |

[Inquiry Desk](demos/inquiry-desk/index.html) показывает обычную отправку, повтор без дубля и ошибку. Демонстрации используют тестовые данные. Файлы HTML автономны, откройте их в браузере после скачивания. Скриншоты PNG показывают более ранние версии макетов. Их можно открыть прямо в GitHub.

Демо Inquiry Desk не подтверждает доставку с tercia.dev. Рабочую форму и получение письма на info@tercia.dev нужно проверять отдельно на домене.
