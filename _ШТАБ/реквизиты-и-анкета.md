## Команда

`?` — **нужно решение.** По факту работают двое: Амир (разработка и продукт)
и партнёр (продажи, переписка с клиниками). Но партнёр **в штате ИП
не состоит** — нет ни трудового договора, ни ГПХ. Писать «команда 2 человека»
можно, писать «сотрудники» — нет.

На сайте сейчас: «команда без прослоек: вы говорите напрямую с тем,
кто отвечает за результат» — это честно и не требует цифры.

## Кейсы

> ⚠️ **Оплаченных клиентских кейсов нет ни одного.** Всё в портфолио —
> собственные демонстрационные проекты. Так и надо их называть.
> Писать «сделали для клиники X» нельзя, пока клиники X не было.

В портфолио **10 работ**, из них **4 с живыми демо**:

| Работа | Демо |
|---|---|
| «Жемчуг» — премиальная стоматология | ✓ `tercia.dev/portfolio/dental-demo/` |
| Сайт ресторана | ✓ `tercia.dev/portfolio/restaurant/` |
| Сайт фитнес-студии | ✓ `tercia.dev/portfolio/fitness/` |
| Четыре лендинга в четырёх стилях | ✓ `tercia.dev/portfolio/landings/` |
| Бот записи к мастеру | макет диалога |
| ИИ-поддержка по базе знаний | макет диалога |
| Пайплайн заявок с сайта | описание |
| Карта лояльности в Telegram | описание |
| Бот вовлечённости для чатов | описание |
| Кросс-постинг | описание |

**«Жемчуг» — вымышленная клиника**, это прямо написано на демо-странице.
Адреса у неё нет, только метро. Показывать её можно и нужно, выдавать
за реальную клиентку — нельзя.

Заказ `lepasta-menu`: в папке 15 фотографий блюд и больше ничего.
Ни вёрстки, ни текста, ни суммы. В кейсы не идёт, пока статус `?`.
