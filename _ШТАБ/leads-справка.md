# `leads.csv` — как им пользоваться

Таблица холодных касаний. Одна строка — одна компания, не одно сообщение.
История переписки живёт в мессенджере, здесь — только текущее состояние.

Файл создан пустым: двадцать одна колонка и ни одной выдуманной строки.
Наполняется выгрузкой по инструкции из [`PROMPT-сбор-базы.md`](PROMPT-сбор-базы.md).

---

## Колонки

| Колонка | Что в ней | Кто заполняет |
|---|---|---|
| `компания` | Название как в карточке на картах | выгрузка |
| `рубрика` | Стоматология, салон, ресторан, фитнес… Определяет, какой блок шаблонов брать | выгрузка |
| `город` | Для московского блока — Москва | выгрузка |
| `адрес` | Нужен для дедупликации по паре «название + адрес» | выгрузка |
| `телефон` | В формате `+7XXXXXXXXXX`, без скобок и пробелов — иначе дубли не склеятся | выгрузка |
| `телеграм` | `@username` или ссылка. Пусто — значит, в Telegram не пишем | выгрузка |
| `email` | Запасной канал | выгрузка |
| `соцсети` | Ссылка на профиль, если другого контакта нет | выгрузка |
| `есть_сайт` | `да` / `нет`. Главный признак приоритета | выгрузка |
| `рейтинг` | Оценка на картах. Ниже 4,5 — повод говорить о «Репутации» | выгрузка |
| `количество_отзывов` | Много отзывов = поток клиентов есть, деньги в компании водятся | выгрузка |
| `источник_данных` | Откуда взята запись: ЕГРЮЛ, реестр лицензий, сайт организации, карточка на картах. **Обязательно** — юрист требует фиксировать источник и обоснование, почему пишем именно этой клинике | выгрузка |
| `наблюдение` | Один конкретный факт из карточки: «нет сайта», «только телефон», «не указаны часы». Подставляется в `{Наблюдение}` | выгрузка, дополняю руками |
| `приоритет` | Число. Считается: много отзывов + нет сайта + дорогая рубрика | выгрузка |
| `уровень_сообщения` | `уровень_1` (персональное демо, 5 в день, текст руками), `уровень_2` (шаблон + наблюдение), `уровень_3` (биржи и каталоги, в личку не идёт) | выгрузка |
| `текст_сообщения` | Готовый текст из `СООБЩЕНИЯ.md` с подставленными переменными. **Не переписывается «покрасивее»** | выгрузка |
| `канал` | `telegram` / `whatsapp` / `почта` / `звонок` / `форма`. Выбирается по тому, какой контакт есть | выгрузка, правлю руками |
| `дата_касания` | `ГГГГ-ММ-ДД` первого сообщения. Пусто — ещё не писал | я |
| `ответ` | Коротко, своими словами: что ответили | я |
| `статус` | См. ниже | я |
| `сумма` | Сумма счёта или сделки, рублями, без пробелов | я |
| `заметки` | Всё остальное: когда перезвонить, кто принимает решение, чего боятся | я |
| `дата_отказа` | Реестр отказов. Ставится в день отказа, после этого обращения прекращаются навсегда | я |

## Статусы

```
новый → написал → ответил → созвон → счёт → оплачен
                     ↓
                  отказ · позже
```

| Статус | Когда ставить |
|---|---|
| `новый` | Строка есть, сообщение не отправлено |
| `написал` | Отправил первое сообщение |
| `ответил` | Ответили хоть что-то — даже «не интересно, но спасибо» |
| `созвон` | Договорились о звонке или встрече |
| `счёт` | Выставлен счёт, ждём оплату |
| `оплачен` | Деньги пришли, работа началась. Дальше строка живёт в `Заказы/` |
| `отказ` | Отказались прямо |
| `позже` | Написал дважды и тишина, либо попросили вернуться потом. Второго дожима нет |

Правило из `СООБЩЕНИЯ.md`: **второго дожима не бывает.** Написал дважды, тишина —
ставим `позже` и возвращаемся не раньше чем через два месяца.

## Темп

> ⚠️ **Изменено 4 ноября по заключению юриста.** Полные правила —
> в [`рассылка-правила.md`](рассылка-правила.md). Коротко: **до пяти писем в день**,
> уникальный текст под каждую клинику, первое письмо **без цены и без услуг**,
> отправка вручную с корпоративного ящика. Прежний потолок считался только
> от риска блокировки аккаунта и статью 18 закона «О рекламе» не учитывал.

Прежний расчёт, оставлен для сравнения: потолок — **30–40 касаний в день**,
из них **не больше 15–20 в Telegram**.
Холодная рассылка с одного аккаунта ловит ограничение примерно на сороковом
сообщении незнакомым людям. Потерять аккаунт, на котором висят все переписки, —
худшее, что может случиться на неделе.

Раскладка по каналам на день:

| Канал | В день | Примечание |
|---|---|---|
| Telegram | 15–20 | Только тем, у кого телеграм указан в карточке |
| WhatsApp | 10 | С прогретого номера. Новый сжигается мгновенно |
| Почта | по здравому смыслу | Отвечают хуже |
| Звонок | сколько осилишь | Самый конверсионный канал и единственный без риска блокировки |
| Форма / директ | остаток | Когда другого контакта нет |

**План на день** собирается сортировкой: `статус = новый`, по убыванию `приоритет`,
первые 30–40 строк, с оглядкой на лимит по `канал = telegram`.

## Чего в этом файле быть не должно

- **Скрипта автоматической рассылки.** Отправляю я руками, по одному.
  Автоотправка с одного аккаунта — это бан на сороковом сообщении.
- **Сетевых брендов и франшиз.** Решение принимает не директор точки.
- **Дублей одной сети по адресам.** Один контакт на сеть.
- **Выдуманных строк.** Пустая таблица честнее наполненной примерами,
  которые потом уйдут в рассылку.

## Закон

Массовая реклама без согласия получателя — статья 18 закона «О рекламе».
На сорока сообщениях в день это никого не заинтересует, на тысяче — может,
а ИП делает отправителя полностью идентифицируемым. Ещё одна причина держать темп.
