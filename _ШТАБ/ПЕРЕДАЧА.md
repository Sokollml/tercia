## 5. Рабочие приёмы и грабли

**Внешний диск.** Папка живёт на `/Volumes/Z Slim`. Диск отключался прямо во время
работы. Поэтому: пушить часто; пути с пробелом и кириллицей — всегда в кавычках.

**Предпросмотр.** Сервер предпросмотра не имеет доступа к `/Volumes`, поэтому файлы
зеркалятся на диск Mac:

```bash
bash "_ШТАБ/preview.sh"     # готовит ~/tercia-preview
```
Дальше `preview_start` с именем: `redesign`, `site`, `landing`, `social`.
Имена и порты — в `.claude/launch.json`, пути постоянные.

**Панель браузера.** Пока панель скрыта или активна другая вкладка, страница считается
скрытой: анимации не идут, снимки выходят чёрными. Перед проверкой — `tabs_select`
на нужную вкладку и скриншот, и только потом замеры.

**gh CLI** лежит в `~/.local/bin/gh` (в PATH его нет). Вход выполнен, аккаунт sokolclimb.

**Отрисовка картинок** (баннеры, посты) — через headless Brave, он уже установлен:
```bash
cd "_ШТАБ/соцсети" && python3 render.py pack-portfolio.json
cd "_ШТАБ/баннеры/исходники" && python3 gen.py services-ru.json kwork
```

**Публикация сайта:**
```bash
cd ~/tercia-preview/landing && git pull
R="/Volumes/Z Slim/tercia/redesign"
cp "$R/08-depth.html"     index.html
cp "$R/dental.html"       dental/index.html
cp "$R/reputation.html"   reputation/index.html
cp "$R/privacy.html"      privacy/index.html
cp "$R/dental-demo.html"  portfolio/dental-demo/index.html
git add -A && git commit -m "..." && git push
```

**Форма заявки.** Бэкенда нет, GitHub Pages — статика. Форма собирает текст
и открывает WhatsApp с подстановкой текста либо Telegram с копией в буфер обмена.
Номера зашиты в скрипте каждой страницы: `WA = '79882716669'`, `TG = 'tercia_it'`.
Когда появится VPS и n8n — заменить на обычный POST на вебхук.

**Демо «Каспий».** Один файл без сборки и зависимостей. Все данные —
в начале скрипта: `DOCS`, `SVC`, `CALC`, `PRICES`, `REVS`, `CASES`, `QUIZ`.
Поменять цену, врача или случай «до / после» — правка одного массива.
Шрифты Unbounded и Onest лежат локально в `assets/fonts`, подключены
через `unicode-range`: кириллица грузится первой, латиница — по надобности.
Растровых картинок нет вообще, вся графика — SVG и CSS: сцена кабинета,
портреты врачей и сцены услуг собраны в объектах `HERO`, `PORTRAITS`, `SCENES`.

**3D-имплант.** Функция `initImplant3D` рисует тело вращения на canvas 2D:
профиль детали задаётся массивом `[высота, радиус]`, дальше сетка, отсечение
задних граней, сортировка по глубине и плоская заливка. Поменять форму —
поправить `screw()`, `abut()` или `crown()`. Модель запускается только после
нажатия и останавливается вне экрана.

**Цены.** Все суммы помечены атрибутом `data-price` — найти и поменять можно
поиском по файлу. Цифры предварительные, их ещё подтверждает владелец.
GitHub Pages пересобирает сайт сам, минуту-две. Файл `CNAME` с `tercia.dev` не трогать.

**Шрифты.** Archivo Black без кириллицы — русский текст в нём превращается в системный.
Для тяжёлых заголовков используется Golos Text 900.
